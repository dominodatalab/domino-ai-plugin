# Getting help

- **A skill gave wrong or outdated instructions, or the MCP server misbehaves:** open a
  [bug report](https://github.com/dominodatalab/domino-ai-plugin/issues/new/choose).
- **You want a skill for a Domino feature that has none:** open a skill request from the same page.
- **Help using Domino itself** (your deployment, your account, a platform error): contact
  [Domino support](https://support.dominodatalab.com/). GitHub issues here are not a support
  channel for the Domino platform.
- **Product documentation:** [docs.domino.ai](https://docs.domino.ai).
- **A security vulnerability:** follow [SECURITY.md](SECURITY.md). Do not open a public issue.
